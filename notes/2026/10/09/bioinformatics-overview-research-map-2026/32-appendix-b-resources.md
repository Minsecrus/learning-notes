# 附录 B：50 个最重要的软件、数据库和在线资源

> 每条：名称 / 类别 / 一句话用途 / 获取方式。
> 
> 

1. **NCBI GenBank** / 序列库 / 公共核酸序列归档 / ncbi\.nlm\.nih\.gov/genbank

2. **ENA** / 序列库 / 欧洲核酸原始数据归档 / ebi\.ac\.uk/ena

3. **SRA** / 原始数据库 / 测序原始读段归档 / ncbi\.nlm\.nih\.gov/sra

4. **Ensembl** / 注释库 / 脊椎动物基因注释与 REST / ensembl\.org

5. **UCSC Genome Browser** / 浏览器 / 基因组轨道可视化与查询 / genome\.ucsc\.edu

6. **RefSeq** / 注释库 / 人工审编参考转录本 / ncbi\.nlm\.nih\.gov/refseq

8. **PDB（RCSB）** / 结构库 / 实验测定大分子结构 / rcsb\.org

9. **AlphaFold DB** / 结构库 / 预测蛋白结构 / alphafold\.ebi\.ac\.uk

10. **Pfam** / 结构域库 / 蛋白家族 HMM / pfam\.xfam\.org

11. **InterPro** / 结构域库 / 整合蛋白家族注释 / ebi\.ac\.uk/interpro

12. **GO（Gene Ontology）** / 本体库 / 基因功能受控词汇 / geneontology\.org

18. **gnomAD** / 群体频率库 / 健康人群等位基因频率 / gnomad\.broadinstitute\.org

19. **COSMIC** / 肿瘤库 / 体细胞突变目录 / cancer\.sanger\.ac\.uk

20. **1000 Genomes** / 群体库 / 人群基因型参考面板 / ncbi\.nlm\.nih\.gov/variation

24. **ENCODE** / 调控库 / 调控元件图谱 / encodeproject\.org

37. **SPAdes** / 组装工具 / 细菌/短读长组装 / cab\.spbu\.ru/software/spades

38. **DESeq2 / edgeR / limma** / 统计 R 包 / 差异表达 / bioconductor\.org

39. **Scanpy** / 单细胞库 / Python 单细胞分析 / scanpy\.readthedocs\.io

40. **Seurat** / 单细胞库 / R 单细胞分析 / satijalab\.org/seurat
