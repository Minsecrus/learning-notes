# 二十、生物信息学数据库生态：一张完整数据库地图

> 主线：数据库不是静态仓库，而是"数据生产者—质控—标准—计算接口"的生态系统。理解一个数据库，要问四件事：**为什么出现、取代了什么、正在被什么取代、如何被程序调用**。成熟度标注沿用全书四档。
> 
> 

生物信息学数据库（bioinformatics database）是把高通量实验产生的海量原始信号，按统一标准变成可检索、可计算、可复现资源的基础设施。按功能可分为五层：**原始归档层（测序原始数据）、组装/注释层（参考序列与基因结构）、分子功能层（蛋白、结构、结构域、本体）、通路与调控层（通路、互作、调控）、变异与疾病层**（群体频率、致病变异、临床队列）。

## 20\.1 原始数据归档与参考序列层

|数据库|收录什么|典型用途|数据规模（量级，截至 2025–2026 公开资料，随时间增长）|如何访问|是否提供 API|研究中如何使用|成熟度|
|---|---|---|---|---|---|---|---|
|**NCBI GenBank**|所有公开提交的核酸序列（含注释），由国际核酸序列协作库（INSDC）三方同步|序列检索、注释、引物/探针设计、进化分析起点|数万亿碱基、数亿条序列条目（持续增长）|ncbi\.nlm\.nih\.gov/genbank|是（Entrez API / E\-utilities）|提交测序结果、下载参考序列、批量检索同源序列|【成熟·标准流程】|
|**ENA**（European Nucleotide Archive）|欧洲侧 INSDC 原始与归档序列，与 GenBank/DDBJ 三站同步|原始测序数据归档、欧洲节点提交|与 GenBank 同量级|ebi\.ac\.uk/ena|是（REST/XML 提交与检索）|大项目（如基因组组装）提交与批量下载|【成熟·标准流程】|
|**SRA**（Sequence Read Archive）|二代/三代测序原始读段（raw reads）归档|公开数据再分析、方法学复现、数据挖掘|数 PB 级、数百万样品|ncbi\.nlm\.nih\.gov/sra|是（E\-utilities \+ sra\-tools 命令行）|下载他人 RNA\-seq/WGS 原始数据重跑流程|【成熟·标准流程】|
|**DDBJ**|亚洲侧 INSDC 节点，与 GenBank/ENA 同步|面向亚洲研究者的序列提交节点|与 GenBank 同步量级|ddbj\.nig\.ac\.jp|是|区域内序列提交与检索|【成熟·标准流程】|
|**Ensembl**|脊椎动物（尤其人、小鼠）基因注释、基因组装配、变异调控|基因结构、转录本、调控元件、变异注释|数百个物种装配|ensembl\.org|是（REST API \+ BioMart \+ FTP）|取基因坐标、转录本结构、批量区域查询|【成熟·标准流程】|
|**UCSC Genome Browser**|人及多物种基因组浏览器，海量轨道（tracks）|可视化、轨道叠加、自定义数据上传浏览|数百物种、数千条轨道|genome\.ucsc\.edu|是（MySQL 公共库、Table Browser、REST）|查看某位点附近信号、下载 BED/VCF、比对多轨道|【成熟·标准流程】|
|**RefSeq**|curated（人工审编）的非冗余参考转录本/蛋白|提供"干净"的参考注释，减少冗余噪声|跨物种数百万条目|ncbi\.nlm\.nih\.gov/refseq|是（E\-utilities）|作为比对/定量的参考转录本集|【成熟·标准流程】|

> 贯穿主线：**GenBank/ENA/DDBJ 是"原始仓库"，RefSeq/Ensembl 是"经过整理的参考层"**。早期只有手工整理的少量序列；高通量测序迫使数据库从"收论文附表"转为"承接 PB 级原始数据"。SRA/ENA 就是为解决 2000 年代后测序数据无处归档而建。

## 20\.2 分子功能与结构层

|数据库|收录什么|典型用途|数据规模|如何访问|是否提供 API|研究中如何使用|成熟度|
|---|---|---|---|---|---|---|---|
|**UniProt**（Swiss\-Prot/TrEMBL）|所有公开蛋白序列与功能注释；Swiss\-Prot 人工审编、TrEMBL 自动预测|蛋白序列获取、功能注释、同源搜索|数亿条蛋白（Swiss\-Prot 数十万人工条目）|uniprot\.org|是（REST API、SPARQL）|取蛋白序列、按功能/物种批量下载|【成熟·标准流程】|
|**PDB**（Protein Data Bank）|实验测定（X 射线/冷冻电镜/NMR）的生物大分子三维结构|结构分析、分子对接基准、AlphaFold 比对|数十万套结构|rcsb\.org（RCSB PDBe/PDBj 镜像）|是（RCSB API、PDBe API）|下载 PDB 坐标、查分辨率/实验方法|【成熟·标准流程】|
|**Pfam**|蛋白家族与结构域的多序列比对与隐马尔可夫模型（HMM）|注释新序列含哪些结构域/家族|数万个家族|pfam\.xfam\.org|是（API、HMMER 批量）|用 HMMER 扫描蛋白找结构域|【成熟·标准流程】|
|**InterPro**|整合 Pfam、PROSITE、PANTHER 等多个家族/结构域库|一站式蛋白功能与家族注释|覆盖绝大多数 UniProt 蛋白|ebi\.ac\.uk/interpro|是（REST）|批量注释蛋白，避免逐个查多个库|【成熟·标准流程】|
|**GO**（Gene Ontology）|受控词汇本体：分子功能/细胞组分/生物过程三大分支|功能富集分析、统一基因注释|数万个术语、跨物种注释|geneontology\.org|是（GO API、AmiGO）|差异基因做 GO enrichment|【成熟·标准流程】|
|**SCOP/CATH**|蛋白结构分类（折叠、超家族、家族）|结构进化、分类基准|覆盖主要 PDB 结构|scop\.rcsb\.org / cathdb\.info|是|按结构折叠归类蛋白|【成熟·标准流程】|

> 主线：**PDB 是"实验结构黄金标准"，但只覆盖不到已知序列的 0\.1%**。AlphaFold 之后出现了 AlphaFold DB 这样的"预测结构库"（见下），正在极大补充 PDB 覆盖度——但预测结构≠实验验证，使用时须区分置信度（pLDDT）。
> 
>

## 20\.5 大型多组学队列与功能基因组层

|数据库|收录什么|典型用途|数据规模|如何访问|是否提供 API|研究中如何使用|成熟度|
|---|---|---|---|---|---|---|---|
|**GEO**（Gene Expression Omnibus）|基因表达/表观等高通量功能基因组实验数据（含矩阵与原始数据链接）|公开表达数据下载、差异分析复现|数十万样本、数万系列|ncbi\.nlm\.nih\.gov/geo|是（GEOparse 等 \+ E\-utilities）|下载他人表达矩阵重分析|【成熟·标准流程】|
|**TCGA**（The Cancer Genome Atlas）|33 种癌症的多组学（基因组/转录组/表观/临床）|癌症多组学整合、biomarker 发现|约 1\.1 万例肿瘤患者|portal\.gdc\.cancer\.gov|是（GDC API \+ gdc\-client）|下载肿瘤 WXS/RNA\-seq/临床表型|【成熟·标准流程】|
|**GTEx**|大量健康供体多组织基因表达/eQTL|组织特异性表达、表达数量性状位点|约千余人、54 组织|gtexportal\.org|是（Portal API）|查某基因在哪种组织高表达、eQTL|【成熟·标准流程】|
|**ENCODE**|调控元件（转录因子结合、开放染色质、组蛋白修饰、RNA）|非编码区功能注释、调控网络|数千个实验、跨百种细胞系/组织|encodeproject\.org|是（DCC API）|注释非编码变异落在哪个调控元件|【成熟·标准流程】|
|**Human Cell Atlas（HCA）**|跨组织/物种的单细胞多组学图谱|细胞类型参考、细胞状态注释|数千万细胞、数百组织（持续增长）|humancellatlas\.org / cellxgene|是（cellxgene、Scanpy 互操作）|作为单细胞参考图谱做细胞类型映射|【快速发展】|
|**AlphaFold DB**|AlphaFold 预测的几乎全部已知蛋白结构|无实验结构时的结构参考|数亿条预测结构|alphafold\.ebi\.ac\.uk|是（RDF/API、批量下载）|无 PDB 时获取近似结构、对接初筛|【快速发展】（预测而非实验，需标注置信度）|

> 贯穿主线：**TCGA/GTEx/ENCODE 是"大科学计划式数据库"**，由联盟产生、统一标准、免费开放；它们取代了早期"小实验室各自整理小表"的模式。HCA 是这一模式在单细胞时代的延续，但数据组织更依赖云互操作（cellxgene）而非单一下载。
> 
> 

## 20\.6 如何选择与使用数据库（实用判断）

1. **原始数据去哪找？** 测序原始读段 → SRA/ENA；表达矩阵 → GEO；临床队列 → GDC\(TCGA\)/IGSR。

2. **要注释一个基因/蛋白？** 序列 → Ensembl/UniProt；结构域 → Pfam/InterPro；功能 → GO；通路 → KEGG/Reactome。

3. **要解读一个变异？** 人群频率 → gnomAD；临床意义 → ClinVar；肿瘤体细胞 → COSMIC。

4. **要做单细胞/空间？** 参考图谱 → HCA/cellxgene；组织表达 → GTEx。

5. **API 优先**：批量分析一律走 API/命令行，不要网页逐条复制；公共库的"网页可看"≠"可大规模复用"。
