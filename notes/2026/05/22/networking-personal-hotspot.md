# 手机个人热点属于什么网络

## 结论

手机个人热点本质上是 **网络共享**（tethering）功能：手机把自己的蜂窝网络共享给电脑、平板或其他设备。

它具体属于哪类网络，要看设备是通过什么方式连接手机：

| 连接方式 | 更准确的网络类型 |
| --- | --- |
| Wi-Fi 连接手机热点 | WLAN（无线局域网） |
| 蓝牙连接手机热点 | PAN（个人区域网） |
| USB 连接手机共享网络 | 有线网络共享 / 点对点连接，也接近个人设备间连接场景 |

## 关键理解

- **Wi-Fi 个人热点**：手机充当一个小型无线接入点（AP），其他设备通过 Wi-Fi 加入这个小局域网，所以更准确地说属于 WLAN。
- **蓝牙共享网络**：蓝牙常用于个人设备之间的短距离互联，因此更接近 PAN。
- **PAN** 的重点不是“名字里有个人”，而是网络范围和连接技术通常围绕个人设备展开，比如蓝牙、USB 等近距离连接。

## 易混点

“个人热点”这个名字容易让人以为它一定是 PAN，但严格分类时应该看连接技术：

- 用 Wi-Fi 连手机热点：主要叫 WLAN。
- 用蓝牙连手机热点：可以归入 PAN。

一句话记忆：

> 手机个人热点是一种网络共享功能；Wi-Fi 热点通常属于 WLAN，蓝牙共享更接近 PAN。
