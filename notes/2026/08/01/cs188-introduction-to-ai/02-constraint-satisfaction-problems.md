# 第二章 约束满足问题

## 本章解决什么问题

约束满足问题（Constraint Satisfaction Problem，CSP）关心的是：给一组变量分配取值，使所有约束同时成立。

典型任务包括：

- 地图着色
- 数独与 N 皇后
- 课程排期
- 资源分配
- 布局与配置

与一般路径搜索相比，CSP 的状态具有明确结构：每个决策都是给某个变量赋值，约束可以在搜索尚未完成时排除大量不可能分支。

## CSP 的形式化定义

一个 CSP 通常写成三个部分：

$$
\operatorname{CSP}=(X,D,C)
$$

- $X=\{X_1,\ldots,X_n\}$：变量集合。
- $D=\{D_1,\ldots,D_n\}$：每个变量的值域，其中 $X_i\in D_i$。
- $C=\{C_1,\ldots,C_m\}$：约束集合。

一个赋值（assignment）可以是部分赋值或完整赋值。若它没有违反任何约束，就称为一致（consistent）。当完整赋值满足全部约束时，它就是一个解。

### 地图着色示例

假设相邻地区不能使用同一种颜色：

```text
变量：WA, NT, SA, Q, NSW, V, T
值域：{红, 绿, 蓝}
约束：每一对相邻地区颜色不同
```

例如：

$$
WA\ne NT,\qquad WA\ne SA,\qquad NT\ne SA
$$

### N 皇后示例

一种紧凑建模是令 $X_i$ 表示第 $i$ 列皇后所在的行：

$$
X_i\in\{1,2,\ldots,N\}
$$

任意两列 $i,j$ 的皇后必须满足：

$$
X_i\ne X_j
$$

以及：

$$
|X_i-X_j|\ne |i-j|
$$

第一条排除同一行，第二条排除同一条对角线。好的变量设计可以显著缩小状态空间；若为棋盘每个格子都建立一个布尔变量，搜索空间会更大，约束也更繁琐。

## 约束的类型

### 一元约束

一元约束只涉及一个变量，例如：

$$
X\ne \text{red}
$$

它可以直接从 $X$ 的值域中删除不允许的值。

### 二元约束

二元约束涉及两个变量，例如：

$$
X\ne Y
$$

许多 CSP 可以表示为二元 CSP。

### 高阶约束

高阶约束同时涉及三个或更多变量，例如：

$$
X+Y+Z=10
$$

全异约束（all-different）要求一组变量取值互不相同。将它简单拆成大量二元不等式是可行的，但专门的全异传播算法往往更强。

## 约束图

对于二元 CSP，可以建立约束图（constraint graph）：

- 节点表示变量。
- 两个变量之间存在约束时，连接一条边。

约束图揭示问题的局部依赖关系。图越稀疏，越有机会把问题分解成较小子问题；图中高度连接的变量则更可能造成冲突。

高阶约束可以使用因子图表示：变量节点与约束因子节点分开，因子连接它所涉及的所有变量。

## 朴素搜索为什么浪费

若有 $n$ 个变量，每个值域大小为 $d$，完整赋值共有：

$$
d^n
$$

把每个“变量—值”组合当作任意行动，还会产生很多等价的赋值顺序。例如先给 $X$ 再给 $Y$，与先给 $Y$ 再给 $X$，最终可能得到同一个部分赋值。

CSP 搜索利用两个事实消除浪费：

1. 每层只给一个尚未赋值的变量赋值。
2. 一旦部分赋值违反约束，立即停止探索该分支。

## 回溯搜索

回溯搜索（backtracking search）是一种深度优先搜索，每次选择一个未赋值变量，并尝试它的候选值。

```text
BACKTRACK(assignment):
    if assignment 已完整:
        return assignment

    X = 选择一个未赋值变量
    for value in X 的候选值:
        if assignment ∪ {X=value} 与约束一致:
            result = BACKTRACK(assignment ∪ {X=value})
            if result 成功:
                return result

    return failure
```

### 回溯与普通 DFS 的差别

回溯搜索直接利用 CSP 的交换性：赋值顺序不同但结果相同的路径不会被当作不同世界状态反复展开。它还在形成完整赋值前持续检查约束。

最坏情况下，回溯仍需要 $O(d^n)$ 次尝试。过滤与排序启发式用于让冲突更早暴露。

## 过滤与约束传播

过滤（filtering）根据当前赋值从其他变量的值域中删除已经不可能的值。约束传播（constraint propagation）会把一次删除造成的影响继续传到更多变量。

### 前向检查

当给变量 $X$ 赋值后，前向检查（forward checking）查看所有与 $X$ 相邻、尚未赋值的变量，并删除与当前赋值冲突的候选值。

```text
赋值 X = red
→ 从所有邻居的值域中删除 red
→ 若某个邻居值域为空，立即回溯
```

前向检查只看从刚赋值变量出发的一步影响。它不能发现两个未赋值变量之间已经形成的未来矛盾。

### 弧一致性

对二元约束 $C(X,Y)$，若 $X$ 的每个候选值 $x$ 都能在 $Y$ 的值域中找到至少一个支持值 $y$，使 $C(x,y)$ 成立，就称有向弧 $X\to Y$ 是一致的。

形式化地：

$$
\forall x\in D_X,\ \exists y\in D_Y:\ C(x,y)=\text{true}
$$

若某个 $x$ 找不到支持值，就可以把它从 $D_X$ 删除。

注意，$X\to Y$ 一致并不自动保证 $Y\to X$ 一致，因此弧具有方向。

### AC-3 算法

AC-3 反复检查可能不一致的弧：

```text
AC-3(csp):
    queue = 所有有向约束弧

    while queue 非空:
        (X, Y) = POP(queue)
        if REVISE(X, Y) 删除了 D_X 中的值:
            if D_X 为空:
                return failure
            for Z in X 的其他邻居:
                把 (Z, X) 放回 queue

    return success
```

当 $D_X$ 发生变化时，原来依赖 $X$ 提供支持的邻居 $Z$ 可能失去支持，所以需要重新检查 $Z\to X$。

弧一致只能保证局部两两兼容。一个弧一致的 CSP 仍可能没有全局解。

## 变量和值的排序

搜索树规模取决于何时发现冲突。排序启发式不改变解集合，只改变尝试顺序。

### 最少剩余值

最少剩余值（Minimum Remaining Values，MRV）优先选择剩余合法值最少的变量：

$$
X=\operatorname*{arg\,min}_{X_i\text{ 未赋值}} |D_i|
$$

它遵循 fail-first 原则：先处理最可能失败的变量，以便尽早回溯。

### 度启发式

若多个变量的 MRV 相同，可以优先选择约束最多未赋值变量的那个，也就是约束图中当前度数更高的变量。

这个变量对剩余问题影响更大，早点确定它通常更有信息量。

### 最少约束值

最少约束值（Least Constraining Value，LCV）优先尝试给邻居留下最多候选值的取值。

```text
选择变量：先挑最难的变量，MRV
选择取值：先试最宽松的值，LCV
```

MRV 的目标是尽早发现当前分支失败；LCV 的目标是在一个分支内尽量保留未来选择。

## 利用图结构

### 独立子问题

若约束图被分成互不相连的连通分量，可以分别求解每个分量，再组合结果。

若各子问题规模为 $n_1,n_2,\ldots,n_k$，分别求解往往远小于直接面对 $d^{n_1+\cdots+n_k}$。

### 树结构 CSP

若约束图是一棵树，可以在线性变量数量级上求解：

1. 选择根节点并确定从父到子的顺序。
2. 从叶子向根执行弧一致过滤。
3. 从根向叶依次选择与父节点一致的值。

若有 $n$ 个变量、值域最大大小为 $d$，典型复杂度为：

$$
O(nd^2)
$$

这比一般 CSP 的指数复杂度好得多。

### 割集条件化

若约束图含环，可以寻找一个较小变量集合，使这些变量固定后剩余图成为树。这个集合称为 cycle cutset。

对大小为 $c$ 的割集枚举 $d^c$ 种赋值，每种赋值下求解树结构 CSP。复杂度主要指数依赖于 $c$，因此当割集很小时很有效。

## CSP 的局部搜索

局部搜索直接从一个完整但可能违反约束的赋值开始，每次修改少量变量以减少冲突。

### Min-Conflicts

Min-Conflicts 是 CSP 常见的局部搜索策略：

1. 随机选择一个当前发生冲突的变量。
2. 给它选择造成冲突最少的值。
3. 重复直到没有冲突或达到步数限制。

它在 N 皇后等结构化问题上常常很有效，但不保证找到解。

### 爬山、模拟退火与遗传算法

- 爬山法每次选择减少冲突最多的邻居，容易停在局部最优或平台。
- 模拟退火以随温度降低的概率接受更差赋值，用来跳出局部区域。
- 遗传算法对完整赋值进行选择、交叉和突变，需要设计能保留有效结构的编码。

局部搜索内存占用小，适合规模很大的 CSP。若任务还需要证明无解，系统性的回溯搜索更合适。

## 一个完整求解流程

以地图着色为例：

```text
1. 用一元约束初始化各变量值域
2. 运行 AC-3 做初始传播
3. 用 MRV 选择下一个地区
4. 用度启发式打破平局
5. 按 LCV 排列颜色
6. 暂时赋值并进行前向检查或 AC-3
7. 若值域为空则撤销赋值
8. 所有变量赋值完成时返回解
```

这可以概括成：

```text
搜索负责枚举必要选择
过滤负责删除不可能选择
排序负责让失败更早出现
结构分解负责缩小相互影响的范围
```

## 常见误区

### 弧一致不等于存在完整解

弧一致检查的是每条边上的局部支持。多个局部兼容选择合在一起时仍可能产生全局矛盾。

### MRV 与 LCV 的方向相反但目标一致

- MRV 选最受限制的变量。
- LCV 选最少限制其他变量的值。

前者尽早暴露失败，后者尽量让当前分支存活。

### 建模质量决定搜索难度

变量过细会扩大状态空间，约束过弱会减少传播效果。全异等全局约束保留更多结构，常能比拆散后的二元约束更强地过滤值域。

### 过滤删除必须能够撤销

回溯离开一个分支时，需要恢复该分支造成的值域删除。实现中通常使用复制、增量日志或可撤销的数据结构。

## 本章速记

```text
CSP = Variables + Domains + Constraints

Backtracking：一次给一个变量赋值
Forward Checking：向前看一层
Arc Consistency：每个值都要在邻居中找到支持
AC-3：值域变化后重新传播影响

MRV：先选候选最少的变量
Degree：平局时选影响最大的变量
LCV：先试给邻居留空间最多的值

图是树：O(nd²)
图有小割集：枚举割集后求树问题
超大问题：可尝试 Min-Conflicts 等局部搜索
```
