# 5. 相对于 RFC 793 的变更

<a id="section-5"></a>

本文废止 RFC 793，同时也废止了曾更新 RFC 793 的 RFC 6093 和 RFC 6528。无论哪份文档，本文都只纳入其中的规范性协议规范和需求；一些用于介绍背景和设计理由的信息性文字可能未被收录。尽管这些文档的规范性内容已全部并入本文，它们的信息性内容对学习和理解 TCP 仍然有价值，仍可作为有效的信息性参考文献。

本文大部分内容取自 RFC 793 第 3 节“功能规范”，并尽量保留原文的结构与版式。

本文纳入了所有针对 RFC 793 提交且已被接受或保留待更新的适用 RFC 勘误（勘误 ID：573、574、700、701、1283、1561、1562、1564、1571、1572、2297、2298、2748、2749、2934、3213、3300、3301、6222）。另有一些勘误因其他变更而不再适用，包括：572、575、1565、1569、2296、3305、3602。

本文纳入了 RFC 1011、RFC 1122 和 RFC 6093 对紧急指针规范所做的变更。RFC 6093 详细讨论了这些变更为何必要。

本文更新了 RFC 793 中关于 RTO 的讨论，改为引用 RFC 6298。RFC 1122 中关于 RTO 的文字原本取代了 RFC 793 中的相应文字；然而，本应更新 RFC 1122 的 RFC 2988，后来又被 RFC 6298 废止。

RFC 1011 包含许多关于 RFC 793 的意见，其中包括对 TCP 规范的一些必要变更。RFC 1122 对这些意见作了展开，并汇集了针对 RFC 793 的其他变更与澄清。其中影响协议的规范性内容已纳入本文，而 RFC 1122 中一些具有历史价值的实现建议和信息性讨论则未纳入。本文现已取代 RFC 793 成为 TCP 规范，并更新 RFC 1011；RFC 1011 中指出的意见也已纳入。

RFC 1122 的内容不限于 TCP 需求，因此本文无法将其整体废止。本文仅标注为“更新”RFC 1122；但应理解为，本文实际上废止了 RFC 1122 中关于 TCP 的全部内容。

本文纳入了 RFC 6528 提出的更安全的初始序列号生成算法。关于该算法所缓解的攻击，以及选择 PRF 算法和管理秘密密钥数据的建议，请参见 RFC 6528。

本文根据 RFC 6429 增加了一条说明，明确指出系统资源管理方面的考虑允许回收连接资源。从这个意义上说，RFC 6429 已被废止：它所描述的澄清现已体现在对 TCP 基础规范的本次更新中。

本文结合常见实现的现状，以及 IETF 就拥塞控制主题发布的 BCP 和标准化轨道文档，充实了拥塞控制实现方面的描述。
