# Learning Notes

这是一个个人学习笔记仓库，用来记录我在学习新概念、技术和工具时整理出来的笔记、路线图、资料清单和实验片段。

内容会比较松散，重点不是形成一本完整教材，而是把每次学习中的关键理解保存下来，方便之后回看和继续扩展。

## 使用说明

这些笔记主要服务于个人学习，内容可能会随着理解加深而持续调整。部分笔记会混合中文和英文技术术语，这是有意为之：中文用于解释，英文保留常见技术名词和原始概念。

如果你刚好看到这里，可以把它当作一组学习索引，而不是权威资料来源。更严谨的内容请结合教材、官方文档和课程材料交叉验证。
